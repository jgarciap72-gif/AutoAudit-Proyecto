\# AutoAudit - Sistema de Auditoría Automatizado para PostgreSQL



\*\*Desarrollado por:\*\* Javier García  

\*\*Universidad:\*\* Universidad Mariano Gálvez de Guatemala  



\## 📌 Descripción del Proyecto

AutoAudit es una plataforma full-stack para el monitoreo y auditoría en tiempo real de bases de datos PostgreSQL. Utiliza procedimientos almacenados PL/SQL para inyectar triggers dinámicos y exponer los cambios en un dashboard web con exportación nativa a archivos `.xlsx`.



\## 🛠️ Tecnologías Utilizadas

\* \*\*Base de Datos:\*\* PostgreSQL 18

\* \*\*Backend:\*\* Node.js, Express.js, `pg` Pool

\* \*\*Frontend:\*\* HTML5, Tailwind CSS, SheetJS



\## 🚀 Pasos para Despliegue

1\. Ejecutar el script `script\_autoaudit.sql` en PostgreSQL.

2\. Instalar dependencias del servidor: `npm install`

3\. Iniciar el backend: `node server.js`

4\. Abrir `index.html` en el navegador.
